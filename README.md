# Portail du Gouvernement du Royaume-Uni — Version 2.0

Version complète et plate, conçue pour GitHub Pages.

## Installation
1. Décompresser le ZIP.
2. Sélectionner tous les fichiers.
3. Les téléverser à la racine du dépôt GitHub.
4. Valider les modifications.

## Contenu
- nouvelle identité visuelle britannique et royale ;
- page d’accueil complète ;
- actualités avec recherche et filtres ;
- Gouvernement et ministères ;
- institutions ;
- diplomatie ;
- Journal officiel avec recherche ;
- archives ;
- illustrations locales ;
- responsive mobile.

Aucun dossier n’est nécessaire : tous les fichiers sont à la racine.
