# Royaume-Uni RP — Version 2.7 Carte vierge et filtres

La carte est entièrement grise par défaut.

Filtres disponibles :
- Mon pays et mes revendications ;
- Alliés ;
- Commerce.

Dans Administration > Territoires, chaque fiche peut être classée comme :
- territoire de votre pays ;
- revendication ;
- entrée de la base Économie ;
- allié ;
- partenaire commercial.

La page Économie affiche uniquement les fiches marquées « Base Économie ».
Les changements restent stockés localement dans le navigateur jusqu’à la future connexion GitHub/CMS.
